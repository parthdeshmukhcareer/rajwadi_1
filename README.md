# Rajwadi E-Commerce Platform

A full-stack e-commerce platform for Rajwadi Rajputi Poshak and ethnic clothing.

## Technology

Frontend:
- React
- Vite

Backend:
- Node.js
- Fastify
- JavaScript ES Modules
- Drizzle ORM

Database:
- Neon PostgreSQL

Payments:
- Razorpay

Media:
- Cloudinary

## Project Structure

frontend/
React storefront

backend/
REST API, authentication, catalogue, cart, checkout and payments

docs/
Technical documentation

## Local Development

Frontend:

cd frontend
npm install
npm run dev

Backend:

cd backend
npm install
npm run dev
